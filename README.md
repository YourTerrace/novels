# novels

閲覧者ごとに見せる記事を変えられる、パスワード保護つきの記事共有ページです。
暗号化と復号はすべてブラウザの中で行い、GitHub には暗号化したデータだけを置きます。

## ページ

| ファイル | 役割 |
|---|---|
| `index.html` | 入口。名前を入力すると、管理者名なら管理ページへ、それ以外は閲覧ページへ進む |
| `admin.html` | 管理ページ。記事の作成・編集、閲覧者の追加、誰に何を見せるかの設定。保存すると GitHub に直接コミットする |
| `viewer.html` | 閲覧ページ。閲覧者名とパスワードで、その人に割り当てられた記事だけを読める |

## はじめかた

1. リポジトリの Settings → Pages で、`main` ブランチを公開元にする
2. GitHub で Fine-grained personal access token を作る
   - Repository access: このリポジトリだけ
   - Permissions: Contents を Read and write
3. 公開ページの `admin.html` を直接開き、管理者名・管理者パスワード・PAT を設定する
4. 次回からは `index.html` に管理者名を入力すると管理ページに進める（設定したブラウザのみ）

## 仕組み

- `data/articles/<id>.enc` … 記事本体。記事ごとのランダムな鍵で AES-GCM 暗号化
- `data/viewers/<hash>.enc` … 閲覧者ごとの本棚（見せる記事の一覧と各記事の鍵）。閲覧者のパスワードで暗号化（PBKDF2-SHA256 60万回 + AES-GCM）。ファイル名は閲覧者名のハッシュ
- `data/admin.enc` … 管理データ（閲覧者・パスワード・記事の鍵）。管理者パスワードで暗号化
- PAT は管理者パスワードで暗号化して、管理者のブラウザの localStorage に保存

## 注意

- 守っているのはパスワードだけです。名前での振り分けは入口を分けているだけで、認証ではありません
- リポジトリは公開なので、暗号ファイルは誰でもダウンロードできます。パスワードは長めにしてください（特に管理者パスワード）
- 閲覧者から外しても、外す前に読まれた内容は取り消せません。記事は保存のたびに鍵を作り直すので、外した後の更新内容は読めなくなります
- Git の履歴には過去の暗号ファイルが残ります
- 保存してから公開ページに反映されるまで、数分かかることがあります
